## Design principles

- **Practise > memorize.** Each toolkit turns a BABOK® concept into something you can *do*.
- **Zero dependency.** Each HTML file works offline, on any browser, on any device.
- **Bilingual by default.** FR/EN toggle on every page — the whole ecosystem is bilingual.
- **Consistent design language.** Slate + amber "analyst's ledger" palette, IBM Plex Mono for structural codes, minimal formatting.
- **Print-friendly.** Every page exports to PDF cleanly for archiving analyses.

---

## Usage

Open the [live site](https://cmkouakou.github.io/ecba/), pick a toolkit, work inside the page, and export a PDF when you want to keep an analysis.

Or clone locally:

```bash
git clone https://github.com/cmkouakou/ecba.git
cd ecba
open index.html
```
